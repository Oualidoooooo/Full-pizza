Connexion au robot

Mise en route

  1. Appuie sur Nouveau code, puis Copier.
  2. Dans MT5 : Outils › Options › Expert Advisors, coche Autoriser WebRequest et ajoute https://ntfy.sh.
  3. Dans les paramètres d'AlertesPro, colle le code dans Appli : code de connexion.
  4. Reviens ici et appuie sur Se connecter. Le message « AlertesPro démarré » apparaît dans Alertes.
  5. Sur iPhone : Partager › Sur l'écran d'accueil. Sur Android : ⋮ › Installer l'application.

Garde ton code pour toi : quiconque le connaît peut lire tes alertes. Les messages restent 12 h sur le relais, l'historique est gardé sur ton téléphone.

Alertes sur Telegram

Reçois chaque pré-alerte, signal et résultat dans Telegram, même téléphone verrouillé.

  1. Dans Telegram, ouvre ton bot (celui créé avec @BotFather) et envoie /start.
  2. Colle ici le jeton donné par BotFather, puis touche Vérifier : tu dois recevoir un message de test.
  3. Dans MT5, paramètres du robot : Telegram = true, colle le même jeton dans Telegram : token du bot et laisse chat id vide : le robot le trouve tout seul.

Le jeton reste sur ce téléphone et n'est envoyé qu'à Telegram. Ne le partage avec personne : il permet de contrôler ton bot.

Alertes même appli fermée

Un navigateur ne peut pas réveiller ton téléphone quand l'appli est fermée. Pour ne rater aucun signal, ajoute l'une de ces deux options :

  1. Appli ntfy (gratuite) : installe ntfy depuis l'App Store ou le Play Store, touche +, colle ton code comme nom de sujet, serveur ntfy.sh. Les signaux sonnent comme un SMS.
  2. Telegram : voir la section juste au-dessus.

Les mises à jour du compte (toutes les 15 min) partent en priorité minimale : elles ne sonnent pas.
