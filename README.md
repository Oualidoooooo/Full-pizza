# Full Pizza — appli de commande

Appli de commande en ligne pour **Full Pizza**, 121 Rue Nationale, 69400 Villefranche-sur-Saône.

## Voir le site

- **Site en ligne (GitHub Pages)** : https://oualidoooooo.github.io/Full-pizza/
- **Version Claude** (privée, réservée au propriétaire) : https://claude.ai/artifact/QAdouwuznFbCj9nJn9F4Wz

Les deux affichent exactement la même version du fichier `index.html`.

## Étape 1 : maquette (ce dossier)

`index.html` contient une maquette complète et cliquable, sans serveur :

- **Appli clients** : carte, pizzas Classique / XL, bi-goût, suppléments, formules, panier, à emporter ou livraison, paiement simulé, suivi en direct, fidélité, infos.
- **Espace patron** : pavé à code (gérant 1234, Yanis 1111, Léa 2222, livreurs Karim 3333 et Sami 4444), commandes du jour, livraisons, appli livreur, stock et pause, bilan, réglages.

Toutes les données sont des exemples. Les prix et règles marqués « à confirmer » doivent être validés par le restaurant.
